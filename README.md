# Checklist de Afazeres — versão web

Site simples feito com React e Vite, pronto para publicar no Vercel.

## Rodar localmente

1. Abra esta pasta no terminal.
2. Execute `npm install`.
3. Execute `npm run dev` e abra o endereço mostrado.

## Publicar no Vercel

Envie esta pasta para um repositório Git e importe o repositório no Vercel. O Vercel usa `vercel.json`: comando de build `npm run build`, saída `dist`.

## Editar perguntas

Edite o array `QUESTIONS` no início de `src/App.jsx`. **Sim** vale `+1`; **Não** vale `-1`. As reações aleatórias e os limites das faixas de pontuação estão no mesmo arquivo.
